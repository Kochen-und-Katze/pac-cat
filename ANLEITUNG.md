# Pac Cat – kurze Anleitung

## Start

Lade `Pac-Cat.exe` aus dem GitHub-Release herunter und starte sie per Doppelklick. Beim ZIP-Download entpackst du zuerst das Paket und öffnest dann `Pac-Cat.exe`. Weitere Projektdateien, Grafiken, Entwicklungswerkzeuge oder Desktop-Verknüpfungen werden nicht benötigt. Windows mit .NET Framework 4.5 oder neuer ist Voraussetzung.

Wähle **Spielwelten**, eine Welt und anschließend ein Level. Die 60 Levelplätze sind direkt auswählbar. Die getrennte Spielausgabe zeigt links nur **Spielwelten** und **Beenden**. Die Verwaltungsseiten der Entwicklungsplattform werden nicht mitgeliefert. Im Spiel öffnet Esc das Spielmenü.

## Tasten

| Taste | Wirkung |
| --- | --- |
| Pfeiltasten | Pac Cat bewegen |
| W, A, S, D | Pac Cat bewegen; in dieser Ausgabe standardmäßig aktiviert |
| Esc | Spielmenü öffnen; im Menü zurück |
| F10 | Zur Spielauswahl zurückkehren |
| R | Aktuelles Level neu starten |

## Spielziel

Sammle die Leckerlis im Labyrinth. Die Anzeige „Noch sammeln“ zeigt die verbleibende Menge. Vermeide Hundeknochen und gefährliche Geister. Futternäpfe, Medkits, Powerobjekte und Katzenbäume beeinflussen Punkte, Gesundheit oder Schutz. Achte auf die Anzeigen für Gesundheit und verbleibende Leben. Die eingeblendeten Hinweise im Spiel erklären den jeweiligen Zustand.

## Speichern

Fortschritt und Highscores liegen unter `%LOCALAPPDATA%\PacCatPlayer\saves\<Ausgabe-ID>`. Der Levelabschluss wird gespeichert. Beim späteren Fortsetzen beginnt das Level erneut am Start; die aktuelle Position wird nicht als jederzeit fortsetzbarer Spielstand gesichert. Die EXE selbst und der Downloadordner werden dadurch nicht verändert. Diese Ausgabe benötigt zum Spielen keine GitHub-Anmeldung.

## Wenn der Start nicht klappt

Prüfe, ob du Windows verwendest und die vollständige EXE heruntergeladen hast. Bei einem ZIP-Paket zuerst entpacken. Die Prüfsumme der EXE steht in `SHA256SUMS.txt`. Eine mögliche Windows-Warnung hängt auch mit der fehlenden digitalen Signatur zusammen. Deaktiviere deshalb nicht pauschal den Virenschutz. Falls eine Fehlermeldung erscheint, notiere ihren Wortlaut.

Die Veröffentlichung ist eine Testversion. Andere Betriebssysteme und ein Browserstart werden nicht unterstützt. Ein zweites Spielerfeld in der Grafik bedeutet nicht, dass diese Ausgabe einen fertigen Mehrspielermodus enthält.
